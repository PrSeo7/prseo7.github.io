- 사이트가 **"외주 개발 서비스 업체"**(Backend & Mobile App Development)로 소개되어 있지만, 실제 방문 목적은 **앱 퍼블리셔의 앱 소개**임. title·description·JSON-LD 모두 경쟁이 심하고 전환도 안 되는 서비스 키워드 위주.

- 기술적 기본기(메타 태그, canonical, 정적 HTML, 헤딩 구조, JSON-LD)는 양호.

## 1순위 — 바로 고칠 것

- [ ] **푸터 링크 404**: `index.html` 푸터의 `/privacy-policy`, `/terms-of-service`는 존재하지 않는 페이지. 실제 개인정보처리방침은 앱별로 `/<앱폴더>/PRIVACY_POLICY.html`에 있음(예: `/easy_vocab/PRIVACY_POLICY.html`). → 푸터를 앱별 방침 링크로 바꾸거나 `/privacy-policy/` 인덱스 페이지를 만들 것. 이용약관 페이지는 아예 없으므로 만들든지 링크를 제거.
- [ ] **sitemap.xml 정리**: `#about`, `#products`, `#contact` 같은 fragment URL은 구글이 모두 같은 페이지로 봄 → 제거. `lastmod`가 2025-01-01에 멈춰 있음. 대신 개인정보처리방침 5개(easy_vocab, jlptn3word200, pro_vocab, tabata_timer, neko_japanese)와 이후 추가할 앱별 페이지를 넣을 것.
- [ ] **og:image / twitter:image 없음**: 두 태그가 주석 처리되어 있음(`images/prseo7-og-image.jpg`는 저장소에 없음). `twitter:card=summary_large_image`인데 이미지가 없어 카톡·X 공유 미리보기가 비어 보임. 1200×630 이미지를 만들고 주석을 해제. EasyVocab 쇼츠 홍보 중이라 중요.
- [ ] **JSON-LD `logo` 값 오류**: `"logo": "https://prseo7.github.io/"`처럼 이미지가 아니라 홈 URL. → `https://prseo7.github.io/images/favicon/android-chrome-512x512.png` 등 실제 이미지로 교체.

## 2순위 — 효과가 가장 큰 개선: 앱별 랜딩 페이지

현재는 앱 4개가 홈의 카드로만 있고, 아이콘도 Font Awesome이라 이미지 검색에 걸리지 않음.

- [ ] 앱마다 페이지 생성: `/jlpt-vocab-master/`, `/easyvocab/`, `/provocab/`, `/tabata-timer/` (+ Neko Japanese)
  - 고유 title/description. 예: "JLPT Vocab Master – N5~N1 단어 플래시카드 앱"
  - 실제 스크린샷(`~/Documents/prseo7/2026xxxx_*_screenshot`에 만든 스토어 스크린샷 재활용), 앱 아이콘
  - 기능 설명, 사용법, FAQ (본문 300~800단어)
  - `SoftwareApplication` JSON-LD (name, operatingSystem, applicationCategory, offers, downloadUrl)
  - 스토어 링크 + 해당 앱 개인정보처리방침 링크
- [ ] 홈 포지셔닝 전환: "Software Development Services" → "앱 퍼블리셔 / 언어 학습·운동 앱" 중심으로 title·description·H1·JSON-LD 수정. JSON-LD의 `serviceType`/`hasOfferCatalog`는 실제 외주 영업 계획이 없으면 제거 검토.
- [ ] **Neko Japanese 누락**: 개인정보처리방침(`neko_japanese/PRIVACY_POLICY.md`)은 있고 App Store에도 출시되어 있지만, 홈 프로젝트 목록·README·JSON-LD에는 없음.

## 4순위 — 작은 것들

- [ ] 스토어 배지 alt가 모두 "App Store" / "Play Store"라 똑같음 → "App Store에서 JLPT Vocab Master 다운로드"처럼 앱 이름을 포함.

- [ ] 무의미한 태그 제거: `meta keywords`, `meta name="title"`, `meta name="language"`(구글이 무시). robots.txt의 `Crawl-delay`도 구글은 무시.

- [ ] `_README.md` / `README.md`가 옛 내용(JLPT N3 Word200 Android 전용). 공개 영향은 없지만 정리 권장.

## 참고 — SEO 범위 밖이지만 발견한 것

- `easy_vocab/PRIVACY_POLICY.md`(2026-09-09 업데이트)에 아직 "Google AdMob for ads"라고 적혀 있음. AdMob 계정은 2026-09-01 폐쇄되었으므로, 앱이 광고 네트워크를 바꾸면(LevelPlay/AppLovin 등) 방침도 함께 수정할 것. 다른 앱 방침도 같은지 확인 필요.
